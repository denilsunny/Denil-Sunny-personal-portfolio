Project Overview

Designed and developed a self-stabilizing platform using an Arduino Nano and MPU6050 6-DoF IMU to maintain a level surface despite external tilts and disturbances. The system uses real-time motion sensing, sensor fusion, and closed-loop servo control to automatically correct the platform's orientation.

Hardware Implementation

The system integrates an Arduino Nano as the main controller, an MPU6050 accelerometer and gyroscope for motion sensing, and three servo motors for platform adjustment. The MPU6050 communicates with the microcontroller through the I²C interface and provides real-time acceleration and angular velocity data.

Arduino Nano — Main Controller
Reads IMU data over I²C, runs the sensor fusion algorithm to compute orientation angles, and generates PWM control signals for all three servo motors in real time.
Main Controller
MPU6050 — 6-DoF IMU
Provides real-time 3-axis acceleration and 3-axis angular velocity measurements. Communicates with the Arduino Nano via I²C. Supplies the raw motion data used by the sensor fusion algorithm to estimate roll and pitch.
Motion Sensor
Servo Motors — Platform Actuators
Three servo motors act on the platform structure to physically adjust its orientation. Each servo is independently controlled via PWM signals to compensate for measured roll and pitch deviations and maintain a level surface.

Working Principle

The system operates as a continuous closed-loop feedback control cycle — measuring, computing, and correcting in real time.

01
IMU Data Acquisition
The MPU6050 continuously measures the platform's motion and orientation, streaming real-time 3-axis accelerometer and gyroscope readings to the Arduino Nano over the I²C bus.
02
Sensor Fusion & Angle Estimation
Accelerometer and gyroscope readings are combined using a sensor fusion algorithm to estimate the platform's roll and pitch angles. Fusion removes the drift inherent in gyroscope integration and the noise in raw accelerometer data, producing a stable, accurate orientation estimate.
03
Control Signal Generation
The Arduino Nano processes the fused orientation measurements and computes the required correction. It generates independent PWM control signals for each of the three servo motors, commanding them to move by a calculated angle to counteract the measured tilt.
04
Servo Actuation & Correction
When the platform tilts, the controller adjusts the servo positions to compensate for the change in orientation. The platform is continuously returned to level through rapid closed-loop feedback and correction — the entire cycle repeating many times per second.

The key to stable operation is sensor fusion — combining the short-term accuracy of the gyroscope with the long-term gravity reference of the accelerometer to produce a tilt estimate that is both fast and drift-free, enabling smooth, continuous stabilization without accumulated error.
