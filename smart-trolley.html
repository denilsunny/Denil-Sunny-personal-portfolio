Project Overview

Developed a Smart Autonomous Trolley Cart that integrates embedded systems, computer vision, machine learning, and IoT to automate shopping assistance. The system uses real-time person detection and tracking to follow a designated user while maintaining a safe distance.

It also incorporates obstacle avoidance and RFID-based automated billing, with purchase information accessible through a connected web platform — creating a seamless, hands-free shopping experience.

Hardware Implementation

The hardware system is built around a Raspberry Pi 4, which serves as the main processing unit. A Pi Camera 2 captures real-time video for person detection and tracking, while a Google Coral USB Accelerator accelerates machine learning inference at the edge.

The system integrates an ESP module for wireless communication, an RFID reader for product identification, and a motor-control system for autonomous movement — working together to support person following, obstacle avoidance, and automated checkout.

Software Implementation

The software combines Python, OpenCV, TensorFlow Lite, and machine learning to implement real-time person tracking and autonomous movement across six integrated modules.

01
Person Detection & Tracking
Implemented camera-based person detection using a TensorFlow Lite object detection model, with a custom belt-identification mechanism using colour-based filtering to distinguish the designated user from other individuals in the scene.
02
Edge AI Processing
Integrated the Google Coral USB Accelerator to run TensorFlow Lite inference on its Edge TPU, dramatically improving real-time tracking performance far beyond what the Raspberry Pi CPU can achieve alone.
03
Autonomous Navigation
Processed the target's bounding box position in the camera frame to determine movement commands, adjust heading direction, and maintain a safe following distance — all in a continuous closed-loop control cycle.
04
Obstacle Avoidance
Integrated obstacle-detection functionality to support safe navigation in dynamic environments where unexpected objects may appear in the trolley's path during tracking.
05
RFID-Based Billing
Implemented product identification and billing logic using RFID tag data — automatically capturing product IDs as items are placed in the trolley and computing a running bill for the user.
06
IoT Communication
Integrated wireless data exchange between the trolley, ESP module, and web platform to display product information and billing updates in real time on a connected web interface accessible by the shopper.

Working Principle

The Smart Autonomous Trolley Cart operates through four integrated stages: person detection, image processing, autonomous movement, and RFID-based checkout.

01
Person Detection & Identification
The Pi Camera 2 continuously captures real-time video frames. The Raspberry Pi 4 processes these frames using a TensorFlow Lite model to detect people. A distinctive wearable belt is identified via colour-based filtering to distinguish the designated user from others.
02
Image Processing & Tracking
The detected person's bounding box and position are analysed to determine their location relative to the trolley. The system evaluates horizontal deviation to identify the required direction and uses the bounding box's vertical position to estimate the user's relative distance.
03
Autonomous Movement & Following
Based on tracking results, the Raspberry Pi generates motor commands. The trolley moves forward when the user is beyond the desired following distance, adjusts direction to keep them centred, and slows or stops when too close or out of view — repeating this continuously.
04
RFID-Based Automated Checkout
When a product with an RFID tag is placed in the trolley, the RFID reader captures its identification data. The ESP module transmits the product information and price to the connected web platform, where the purchase details and running bill are updated for the user to view.

Project Outcome

Developed and tested a functional autonomous trolley prototype capable of following a designated user, detecting obstacles, and supporting RFID-based automated billing.

The project demonstrated a complete end-to-end integration of computer vision, edge AI, embedded systems, and IoT — from real-time ML inference through to wireless billing — all running on compact, low-power hardware in a mobile platform.
